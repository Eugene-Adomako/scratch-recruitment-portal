# 🚀 Scratch Group Enterprise Recruitment Portal

A world-class, professional HR Recruitment and Talent Management SaaS platform built for the **Scratch Group of Companies**. This system manages the entire employee lifecycle—from job vacancy advertisement to proactive recruitment workflows and internal staff management.

## 💎 Design Philosophy
*   **Neo-Brutalism:** High-contrast, bold job selection cards with luxurious gold-hover effects.
*   **SaaS Minimalism:** Clean, white-space-heavy dashboards for distraction-free management.
*   **Glassmorphism:** Transparent, blur-effect sidebars for a premium corporate aesthetic.
*   **Full-Responsive UI:** Expertly crafted to scale from desktop monitors to mobile devices.

## 🛠 Key Features

### 🏢 For HR Recruitment Team
*   **Intelligence Hub:** Real-time metrics tracking Total Applicants, Staff Counts, and Hires.
*   **Pipeline Management:** Proactive 9-step workflow control (Verification -> Interview -> Medical -> Enroll).
*   **Integrated Scheduling:** Automated Interview and Medical date/time picker with candidate confirmation logic.
*   **Job Broadcast System:** Tools to create, manage, and publish job vacancies instantly.
*   **Staff Control:** Capability to manually enroll new staff or manage existing employee records.

### 👤 For Candidates / Applicants
*   **Search-Centric Landing:** High-end job discovery search bar.
*   **Interactive Application Form:** Detailed credential submission including Statement of Purpose and PDF CV upload (Max 5MB).
*   **Live Status Tracker:** A responsive progress bar that reacts instantly to HR decisions.
*   **AI Support Agent:** 24/7 virtual assistant to guide applicants through the enrollment process.

### 💼 For Employees / Staff
*   **Internal Portal:** Secure access to internal company resources.
*   **Security Protocol:** Automated password reset requirements for HR-generated accounts.

## 🚀 Tech Stack
*   **Backend:** PHP 8.x
*   **Database:** MariaDB / MySQL
*   **Frontend:** HTML5, CSS3 (Inter & Orbitron Typography)
*   **Framework:** Bootstrap 5
*   **Charts:** Chart.js (Reactive Analytics)
*   **Icons:** Bootstrap Icons

## ⚙️ Installation Guide
1.  **Clone the Repository:**
    ```bash
    git clone https://github.com/Eugene-Adomako/scratch-recruitment-portal.git
    ```
2.  **Environment Setup:**
    *   Move the project folder to your local server directory (e.g., `C:/xampp/htdocs/scratch/`).
    *   Ensure the `uploads/` folder exists and has write permissions.
3.  **Database Configuration:**
    *   Create a new database named `scratch_group` in phpMyAdmin.
    *   Import the provided `scratch_group.sql` file.
4.  **Launch:**
    *   Navigate to `http://localhost/scratch/index.php` in your browser.
